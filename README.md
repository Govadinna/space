# Seamless Space · Fabric 26.3 · 0.12.1

**Скачать:** [мод 0.12.1 (.jar)](dist/seamless-space-0.12.1.jar?raw=true) · [комплект с Fabric API (.zip)](dist/seamless-space-0.12.1-mc26.3.zip?raw=true) · [инструкция по установке](dist/INSTALL-RU.txt).

Солнечная система, обычные планетные чанки и полёт настоящего игрока в творческом режиме. Земля использует seed, генератор и биомы текущего Overworld. Геометрия космоса считается в двойной точности; интерактивные поверхности остаются измерениями Minecraft.

## Установка

1. Закрой игру. Замени старый `seamless-space-*.jar` в `mods` на **`seamless-space-0.12.1.jar`**. Одновременно устанавливай одну версию мода.
2. Нужны **Minecraft Java 26.3**, **Fabric Loader 0.19.5+**, **Java 25** и **Fabric API 0.163.0+26.3**.
3. Комплект `seamless-space-0.12.1-mc26.3.zip` содержит мод, Fabric API, инструкцию и снимки игрового клиента.
4. Открой одиночный творческий мир. Существующие настройки seed/scale сохраняются.

macOS: `~/Library/Application Support/minecraft/mods`; Windows: `%APPDATA%\.minecraft\mods`.

## Исправления 0.12.1

Орбитальное движение читает обработанные оси обычного креатива: W/S — горизонтально вперёд/назад, A/D — влево/вправо, Space/Shift — вверх/вниз. Оно больше не зависит от смещения нативного игрока и порога 100 блоков за тик: задержка чанков не должна фиксировать орбитальную камеру. Исправлен знак бокового движения. Скорость нативного игрока над атмосферой ограничена отдельно, чтобы не заставлять Overworld генерировать наземные чанки с межпланетной скоростью; выбранная орбитальная скорость сохраняется.

Короткая проверка клиента проверяет подъём через 2000, движение и положительное смещение D по правой оси камеры. Скриншоты в обычном тесте больше не создаются.

## Исправления 0.12

При вылете игрок остаётся в текущем измерении и в обычном креативе: без переноса в пустой мир, обнуления скорости и сброса удерживаемых клавиш. Скорость плавно растёт по одной формуле до и после высоты 2000. `+`/`−` меняют множитель. Орбитальная система координат нужна для больших расстояний; при посадке на другую планету её настоящие чанки всё ещё относятся к отдельному измерению.

Исправлено наложение плоской LOD-площадки на сферу: с высотой геометрия полностью становится сферической. Земная блочная LOD плавно исчезает между 400 и 1200 блоками; выше остаётся единая орбитальная сфера. Это устраняет наложенный участок со снимка, но границы содержимого шести карт Земли и различия с настоящими чанками ещё возможны.

Подготовка чанков, ограниченная загрузка впереди и марсианская дымка сохранены. Обычная проверка клиента теперь короткая: удержание Space через 2000, затем движение вперёд/вбок и один снимок. Старая галерея запускается только отдельной настройкой `seamlessspace.fullGallery` и не является проверкой нового маршрута.

Земля использует текущий Overworld и его seed. Генераторы существующих планет не изменены, постройки сохраняются. Высота строительства до Y=2031. Нативная скорость ограничена; множитель больших орбитальных расстояний применяется дополнительно. Полная бесшовность посадки и постоянный FPS не гарантируются.

## Управление

| Клавиша / команда | Действие |
| --- | --- |
| Двойной Space, WASD, Space/Shift | Обычный полёт креатива |
| `+` / `−` | Изменить множитель скорости |
| `/space speed 8` | Установить множитель ×8 |
| Ctrl | Ускорение |
| B | Тормоз в космосе |
| F7 | Необязательный быстрый подъём на орбиту |
| F6 | Возврат к месту вылета на Земле |
| G / `/space land` | Запрос входа в близкую поверхность |
| N | Следующая цель в космосе |
| `/space planets` | Список небесных тел, расстояний и старых миров |
| `/space target 5` | Навести вид на Марс; лететь нужно самостоятельно |
| `/space landmarks` | Показать координаты геологических ориентиров |
| Подзорная труба + колесо | Увеличение ×10…×1000 |

Цели 1–10: Земля, Луна, Меркурий, Венера, Марс, Юпитер, Сатурн, Уран, Нептун, Солнце. У планет свои геологические шумы, кратеры, хребты и материалы. Кристаллы Нептуна, шестиугольник Сатурна, солнечные гранулы, пятна и волокнистые арки сохранены из 0.9. Солнечные арки ограничены 18 000 вершинами и буфером 648 000 байт, без увеличения лимитов частиц.

Гравитация относительно Земли: Луна 0,165; Меркурий/Марс 0,38; Венера 0,904; Юпитер 2,528; Сатурн 1,065; Уран 0,886; Нептун 1,137; игровое Солнце 2,8. Туман гигантов усиливается внизу и ослабевает с высотой. Кольца Сатурна и Урана используют полосы вдали и локальные повёрнутые кубики вблизи.

## Сохранения и ограничения

- **Строительство Y=-64…2031** в Overworld и планетных мирах. Незер/Энд не изменены. Мод заменяет тип измерения Overworld; другие датапаки высоты могут конфликтовать.
- Земной генератор и существующие блоки не заменяются. Новый Марс создаётся отдельно; старый доступен как **[старый мир]**. Сатурн/Нептун остаются `solar-v4/`, остальные новые тела — `solar-v3/`.
- Не меняй seed/scale обжитого сохранения. Не открывай сохранение с планетными блоками старым модом или без него.
- Это **не единое сферическое воксельное измерение**. Отдельные измерения, локально плоские чанки и перенос между ними сохраняются. Скрытие загрузочной заставки и сохранение камеры не гарантируют отсутствия любых пауз или появления мелких объектов при загрузке. Кубические карты имеют границы; плоский Overworld не становится замкнутой сферой с бесконечно непрерывным ландшафтом на всех рёбрах карт.
- Глобальная карта — высоты/биомы генератора, а не полный рендер всех чанков, деревьев и построек. Орбитальный кэш хранит до 4096 чанк-участков; интерьеры и нижние стороны навесов не воспроизводятся. Для записи крупной постройки облети её перед вылетом.
- Газовые гиганты имеют условную твёрдую поверхность. Кубики колец визуальные, без добычи и коллизии. Настоящие чанки освещает система Minecraft; физического глобального освещения нет.
- Перенос кораблей Create/Aeronautics между измерениями не реализован. Мультиплеер, Iris/Sodium и Vulkan не проверялись.

## Настройки и сборка

`config/seamlessspace.json` редактируется при закрытой игре. Сохранены `solarSystem`, `compactSystem`, `seed`, `scale`, `entryAltitude`, `maxCruiseSpeed`, `renderHeight`, `starBrightness`, `starSize`, `automaticLanding`, `automaticEntry`, `showHud`. В обычной солнечной системе выход около 2000 блоков, автоматический вход в чанки — не ниже 1200, даже если старое `landingAltitude` равно 64. `automaticLanding: false` оставляет ручной запрос G.

`solarSystem: false, compactSystem: true` включает прежний компактный каталог с расстояниями около 26–35 тысяч блоков. В основной солнечной системе расстояния остаются увеличенными; переключение каталогов не переносит постройки.

С **JDK 25**: `./gradlew build` (Windows: `gradlew.bat build`). Результат — `build/libs/seamless-space-0.12.1.jar`; `-sources.jar` в mods не нужен. Зависимости и Gradle Wrapper входят в архив исходников.

Проверки: `./gradlew test`, `./gradlew validateSpaceShaders`, `./gradlew runGameTest`, `./gradlew runClientGameTest`. Клиент проверяет нативное перемещение персонажа в космосе, творческие способности, посадку с сохранением камеры, высокие блоки, телескоп, полюса Земли/Луны и обычный подлёт к Земле с последующей посадкой. Снимки находятся в `dist/screenshots/v10/` и комплекте релиза. Тесты не являются гарантией FPS на любом компьютере.
